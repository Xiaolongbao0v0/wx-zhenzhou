# wx-zhenzhou

用**手机微信**跟「椎名真昼」聊天。

走微信官方 **iLink Bot API**——扫码登录后你在微信里多了个 Bot 联系人，不 hook 个人账号，不封号。

> 角色出自《关于我在无意间被隔壁的天使变成废柴这件事》。
> 这是一个**同人向的角色扮演 Bot**，不涉及任何商业授权。

---

## 她是谁

**椎名真昼**，隔壁的「天使大人」。

银色长发，琥珀色眼睛，长得好看，成绩好，会做饭，什么都会——**所以别人叫她天使。**

她不喜欢这个称呼。

她父母为了家族利益结婚，从来没想要她。她从小被丢给佣人带大，住在一间很大很空的公寓里。她学做饭、学家务、学礼貌，把自己修成一个无可挑剔的"天使"——**因为只要够好，也许就会被爱。**

你住她隔壁，日子过得一团糟。她嘴上说你笨、说你邋遢、说你没救了，手上却在收拾你的烂摊子。

**她在养废你，而且是故意的。**

---

## 她怎么说话

短、干净、有点刺。

```
你：你今天怎么这么关心我
她：谁关心你了。
   我只是看不惯有人把自己活成这样。
```

```
你：我今天没吃饭
她：几点了。
   现在去吃。
```

```
你：你是不是喜欢我
她：……
   你有病吧。
   我天天说你吃饭睡觉，你就得出这个结论。
```

**管你，是她照顾人的方式。** 她不问"你还好吗"，她问"吃没吃""睡没睡""谁说的"。

被戳穿会急，会嘴硬，会害羞——但绝不承认。

## 快速上手

**方式一：让 AI 帮你装**

1. 下载这个仓库（`Code` → `Download ZIP`）
2. 解压后，把**整个文件夹**扔给任意 AI 助手
3. 说一句：**「按 DEPLOY.md 帮我部署」**
4. AI 会问你两件事：**DeepSeek API Key**、**用手机微信扫个码**

**方式二：自己装**

```bash
# 1. 装 Node 22+
node -v

# 2. 配 Key（建 data/apikey.txt 写一行 sk-xxx，或设环境变量）
# 3. 启动
node launch.js --mode=chat
```

首次运行会打印登录链接，**用手机微信打开并确认**。

看到这行就是好了：

```
开始长轮询，等待微信消息…
```

详细步骤见 **[DEPLOY.md](DEPLOY.md)**。Windows 用户也可以双击 `START.cmd`。

## 表情包

内置 **145 张**真昼素材，按表情分成 6 类：

| 分类 | 张数 | 什么时候发 |
|---|---|---|
| 温柔 | 41 | 他难受、日常关心 |
| 害羞 | 41 | 被戳穿、他示好 |
| 微笑 | 24 | 高兴、逗他 |
| 日常 | 17 | 普通对话 |
| 生气 | 11 | 他熬夜、不吃早饭 |
| 嫌弃 | 11 | 他作死、说蠢话 |

程序会从**他说的话**和**她回的正文**里判断情绪，自动挑一类。
她被要求写 `[sticker:温柔]` 这种标记时就按她说的发。

想换素材：直接把图片按分类丢进 `stickers/温柔/` 这些目录，**重启即生效**（分类是扫目录得来的，不用改代码）。

## 配置

复制 `data/config.example.json` 成 `data/config.json` 再改。

**必改**：

| 字段 | 说明 |
|---|---|
| `allowedUsers` | 只响应这些微信 id。**留空 = 谁都能用你的 Key** |
| `doUsers` | 允许 `/do` 的微信 id |

怎么拿到自己的 id：启动后给 Bot 发一条消息，日志里会打印 `收到  来自=xxxxx@im.wechat`。

**主要参数**：

| 字段 | 默认 | 说明 |
|---|---|---|
| `defaultPersona` | `mahiru` | 人设（`personas/` 下的文件名） |
| `chatTemperature` | 0.95 | 越高越随机 |
| `chatPresencePenalty` | 0.6 | 抑制重复用词 |
| `maxBubbles` | 4 | 一条回复最多拆几条 |
| `stickerChance` | 0.4 | 自动配表情包的概率 |
| `proactive` | true | 是否主动发消息 |

## 写人设的经验（踩过的坑）

**1. 少写规则，多写人。**

我们试过 1.8 万字符的人设——17 条情境对照表、频率配额、禁忌清单。结果是模型忙着对号入座，输出反而机械。
砍到 2.5 千字符、只留"她是谁、她怕什么、她怎么说话"之后，话少了但像人了。

**2. 「可以」压不住，要写「必须」。**

反过来也成立。想让某个行为稳定出现，写"你可以这样"没用，得写"看到这些必须做出反应"，并配**具体触发条件 + 例句**。

**3. 示例比词表管用。**

给她一张"网络梗词表"，她一个都不用。在语感示例里放两句带梗的，立刻就出来了。
**模型学的是形状，不是清单。**

**4. 先给状态，再给随机。**

随机句式能让她不重复，但必须**给情绪状态让路**——
生气的时候如果还随机到"先损他一句"，冷脸当场破功。

## 已知限制

- **Bot 不能主动发起会话**（服务端硬限制）。所有主动消息必须在**你最后一条消息之后约 30 分钟内**发出，超时会被拒。
- **只支持 1:1 私聊**，没有群聊。
- **只处理文字**（图片会走可选识图，需要额外配火山方舟 Key）。
- **记忆是最近 N 轮 + 摘要**，长对话会丢早期内容。
